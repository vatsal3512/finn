⏺ The flow for a new company is:

1. **Resolve ticker.** Search uses NSE's official equity list (about 2,618 listed companies in the current file). It accepts a company name or symbol. A ticker outside NSE is rejected with a clear message.
2. **Check cache.** The 23 demo reports are shipped with the app. A live report is stored in Vercel Blob and reused for 7 days. If there's no recent report, the research API starts a new run and streams progress to the phone.
3. **Gather source material.** It fetches the latest annual report, the last four earnings-call transcripts and five years of financial statements. It checks screener.in and NSE announcements because the screener transcript list can lag behind exchange filings.
4. **Cash quality.** Python calculates how much reported profit turns into operating cash over five years. This is deterministic and doesn't need an LLM.
5. **Extract management promises.** Gemini Flash reads each transcript and extracts candidate promises with the exact supporting sentence.
6. **Verify quotes.** Code searches the source PDF text for each quote and stores the page reference. A quote that cannot be found is dropped.
7. **Grade measurable promises.** Python compares targets with later reported numbers, including metric, period and unit. It marks them missed, met, on track or open. Revised guidance is kept as a timeline.
8. **Judge the remaining points.** The model writes the bull/bear analysis and handles claims that can't be graded with a simple numeric rule. Its claims still need source quotes.

A live Tata Power run took 45 seconds and all 56 quoted excerpts matched. Trent had no call transcripts, so it returned an accounts-only report instead of failing or making up calls. The design rule is still: **the model reads and explains; code verifies and calculates.**
